コンポーネントの作り方について

- html について、動的に増減しないものについては index.html にどんどん書いていく
- CSSは tailwindcss ライクなものを書きたい
- JS は、機能ごとにファイルを分ける。イベント処理についてはhtmlのon属性に直書き、そのためにheadで宣言
- JS 動的に増減するものは最小限の構成で components にまとめるでどうか。

と思ったけど、やっぱり全部JSファイルにまとめてしまうほうが楽だった。
CSSはstyle.css にどんどん放り込んでいく。
